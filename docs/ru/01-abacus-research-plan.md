# Краткое резюме (RU, вторичный язык)

Это **вторичный** русскоязычный пересказ. Канонический документ: `01-ABACUS-RESEARCH-PLAN.md`
(английский). При расхождениях верен английский оригинал.

**Abacus** — исследование: можно ли построить **permissionless PoW из GPU-оптимальной линейной
алгебры** (matmul / NTT / MSM) с **дешёвой вероятностной проверкой** (Freivalds, sumcheck/GKR,
KZG). GPU здесь гарантирован (это узкие места всех zk-пруверов), в отличие от решёточного SIS-PoW.

Главный научный вопрос — **линейность**: майнер может раскладывать, предвычислять и
переиспользовать, поэтому нужен **нелинейный якорь** (хеш частичных результатов, шум, свежая
случайность до тяжёлой работы). Есть «полезная» инстанциация: если работа = *само доказательство*
(NTT/MSM для ZK), у PoW появляется **реальный покупатель**.

Документ — стартовый план (E0–E7, тест-план, stop-критерии), а не протокол и не монета.
Критическая тропа и решающие эксперименты: `docs/CRITICAL-PATH.md`.
